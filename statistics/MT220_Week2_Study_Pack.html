Part A — Measures of Central Tendency

A measure of central tendency is one number that represents the whole dataset — its "middle" or most typical value. Three main measures: Mean (average), Median (middle value), Mode (most frequent value).

1. Arithmetic Mean (Slides 6–8)

Data typeFormulaSlide example
Ungrouped (raw)X̄ = ΣX / n10, 15, 20, 25, 30 → 100/5 = 20
Discrete frequencyX̄ = ΣfX / ΣfX 10, 20, 30; f 2, 5, 3 → 210/10 = 21
Grouped (classes)X̄ = Σfx / N, x = midpointRunning example → 745/30 = 24.83
  • Midpoint x = (Lower limit + Upper limit) / 2. We assume all values of a class sit at its midpoint.
  • Classes 1–10, 11–20 … are inclusive (they have a gap), so their true class boundaries are 0.5–10.5, 10.5–20.5 … Boundaries are used for median, mode and quartiles — not for the midpoint.
  • Excel: =AVERAGE(A1:A5); frequency mean =SUM(fx)/SUM(f).

2. Weighted Mean (Slide 9)

X̄w = ΣWX / ΣW — used when values differ in importance (credit hours, quantities).
Slide: Maths 80 (4 cr), English 70 (2), Statistics 90 (3) → 730/9 = 81.1 (simple mean = 80).
If all weights are equal → weighted mean = simple mean.

3. Median (Slides 11–13)

  • Raw data: sort ascending. Odd n → middle value; even n → average of the two middle values. (4, 7, 9, 10, 15 → 9; 3, 4, 5, 8, 10, 12 → (5+8)/2 = 6.5)
  • Discrete frequency: find n/2, then the first c.f. ≥ n/2. (n = 12, n/2 = 6, first c.f. ≥ 6 is 10 at X = 30 → Median = 30)
  • Grouped: Median = L + [(N/2 − cf) / f] × c
    L = lower boundary of the median class · cf = c.f. before it · f = its frequency · c = class width.
    Running example: N/2 = 15 → class 21–30; Median = 20.5 + [(15 − 10)/10] × 10 = 25.5

4. Mode (Slides 15–16)

  • Raw: the most frequent value. One mode = unimodal; two+ = bimodal/multimodal; all different = no mode. Excel =MODE.SNGL.
  • Grouped: Mode = L + [(f₁ − f₀) / (2f₁ − f₀ − f₂)] × c
    f₁ = frequency of modal class (highest f), f₀ = class before, f₂ = class after (use 0 if none).
    Running example: 20.5 + [(10 − 6)/(20 − 6 − 8)] × 10 = 20.5 + 6.67 = 27.17

5. Empirical Relationship (Slide 17)

Mode = 3 × Median − 2 × Mean (moderately skewed data only; an approximation).
Slide: Mean 20, Median 18 → Mode = 54 − 40 = 14.

6. Quartiles (Slides 19–21)

Quartiles split ordered data into 4 equal parts: Q₁ (25% below), Q₂ = Median (50%), Q₃ (75%).

  • Raw data: positions Q₁ = (n+1)/4, Q₂ = 2(n+1)/4, Q₃ = 3(n+1)/4, then interpolate.
    Slide: 5, 6, 7, 8, 9, 10, 11, 12 → Q₁ = 6 + 0.25(1) = 6.25, Q₂ = 8.5, Q₃ = 10.75. Excel =QUARTILE.INC(range, k).
  • Grouped: Qk = L + [(kN/4 − cf) / f] × c
    Running example: Q₁: N/4 = 7.5 → 10.5 + [(7.5 − 4)/6] × 10 = 16.33; Q₃: 3N/4 = 22.5 → 30.5 + [(22.5 − 20)/8] × 10 = 33.63

7. IQR and Quartile Deviation (Slide 22)

IQR = Q₃ − Q₁ — spread of the middle 50%; less affected by extreme values than the range.
QD = IQR / 2 (semi-interquartile range).
Running example: IQR = 33.63 − 16.33 = 17.29 (17.30 with rounded Q's); QD = 8.65.

8. Box Plot (Slide 23)

Five-number summary: Min, Q₁, Median, Q₃, Max. The box = middle 50% (IQR), line inside = median, whiskers to min and max; points beyond whiskers = possible outliers.
Slide: 5, 6, 7, 8, 9, 10, 11, 12 → Min 5, Q₁ 6.25, Median 8.5, Q₃ 10.75, Max 12.

9. Applications (Slide 25)

  • AI: mean accuracy across cross-validation folds; median inference time when a few requests spike (outliers).
  • Cyber: mean/median response time = performance baseline; mode = most common alert type in logs.

Part B — Measures of Dispersion

Dispersion (variation / spread) = how far values are scattered around the mean. Same mean can hide very different spreads: Class A 45–49 (mean 47, consistent) vs Class B 20–80 (mean 50, inconsistent). Measures: Range, IQR, Variance, S.D., C.V.

10. Range and Coefficient of Range (Slide 28)

Range = L − S (largest − smallest). Quick, but uses only the two extremes.
Coeff. of Range = (L − S) / (L + S) — unit-free, for comparing datasets.
Slide: 150 … 170 cm → Range = 20 cm; Coeff. = 20/320 = 0.0625 = 6.25%.

11. Variance and Standard Deviation (Slides 29–31)

DataVariance σ²S.D. σ
UngroupedΣ(X − X̄)² / n√[Σ(X − X̄)² / n]
Frequency (shortcut)Σfx²/N − (Σfx/N)²√[Σfx²/N − (Σfx/N)²]
  • Variance is in squared units; S.D. is back in the original units. Smaller S.D. → more consistent.
  • Slide (ungrouped): 2, 4, 6, 8, 10 → Σ(X − X̄)² = 40 → σ² = 8, σ = 2.83.
  • Slide (grouped): 22287.5/30 − (745/30)² = 742.92 − 616.69 = 126.22, σ = 11.24.
  • ⚠ fx² = f × x² (e.g. 4 × 5.5² = 121) — not (fx)². ⚠ Check: Σ(X − X̄) must equal 0.

12. Coefficient of Variation (Slides 32–33)

C.V. = (σ / X̄) × 100% — relative spread; compares datasets with different units or means. Lower C.V. = more consistent.
Slide Example 4.9: Price C.V. = 41.62%, Life C.V. = 37.15% → Price varies more, even though Life's S.D. (78.38) is much larger than Price's (7.66).

13. Applications of Dispersion (Slide 35)

  • AI: low variance across folds = stable model; high variance = overfitting (bias–variance trade-off).
  • Cyber: 3-sigma rule — flag values beyond mean ± 3σ; a DDoS attack sharply increases variance of request rates.

Part C — Skewness and Kurtosis

14. Skewness (Slides 37–38)

Skewness = lack of symmetry.

TypeTailOrderSk
Symmetric—Mean = Median = Mode0
Positive (right)long right tailMean > Median > Mode> 0
Negative (left)long left tailMean < Median < Mode< 0

Karl Pearson: Sk = (Mean − Mode) / σ, or Sk = 3(Mean − Median) / σ when the mode is unstable.
Running example: (24.83 − 27.17)/11.24 = −0.21; 3(24.83 − 25.5)/11.24 = −0.18 → slightly negatively skewed.

15. Kurtosis (Slides 39–40)

Kurtosis = peakedness / tail-heaviness compared with Normal. β₂ = [Σf(X − X̄)⁴/N] ÷ [Σf(X − X̄)²/N]² = m₄ / m₂².

Typeβ₂Excess (β₂ − 3)Shape
Mesokurtic= 3= 0Normal
Leptokurtic> 3> 0Peaked, fat tails, more outliers
Platykurtic< 3< 0Flat, fewer/milder outliers

⚠ Excel =KURT gives excess kurtosis — compare with 0, not 3.

16. Applications (Slide 41)

  • Right-skewed features (income, file size) → log-transform before training.
  • High kurtosis → outliers more frequent than Normal predicts (fraud detection uses it).
  • Response times are right-skewed — assuming Normal can create false anomalies.

Top Mistakes to Avoid

  1. Using class limits instead of boundaries for L in median/mode/quartiles.
  2. Using the c.f. of the median class instead of the c.f. before it.
  3. Forgetting to sort raw data before finding the median or quartiles.
  4. Writing (fx)² instead of f × x².
  5. Forgetting the square root (giving the variance as the S.D.).
  6. Comparing S.D.s of datasets with different means/units — use C.V.
  7. Comparing Excel KURT with 3 — it is already excess kurtosis (compare with 0).
  8. Using f₀ or f₂ from the wrong classes in the mode formula (0 if no class exists).

Part E — Exam-Style Question: Grouped Frequency Distribution & Box Plot

Your teacher's paper question gives raw data and asks you to (a) build the table, (b) find mean/median/mode, (c) Q₁ and Q₃, (d) draw a box plot, (e) comment on the shape. Total 25 marks. Learn this exact routine.

Step-by-step routine (memorise)

  1. Sort / scan the data. Note the minimum and maximum (you need them for the box plot).
  2. Write the classes. Start where told (e.g. 31–50). Upper limit = lower + width − 1. Keep adding the width until the last class contains the maximum.
  3. Class boundaries = lower limit − 0.5 and upper limit + 0.5 (because there is a gap of 1 between classes).
  4. Tally: go through the data once, putting a stroke in the right class; every 5th stroke crosses the previous four (). Then count → f.
  5. Check Σf = n (number of observations). If not, you missed or double-counted a value.
  6. Midpoint x = (lower limit + upper limit) / 2.
  7. Cumulative frequency c.f. = running total of f; the last c.f. must equal N.
  8. (b) Mean = Σfx/N. Median: N/2 → median class → L + [(N/2 − cf)/f] × c. Mode: highest f → L + [(f₁ − f₀)/(2f₁ − f₀ − f₂)] × c. Always name the median class and modal class — they carry marks.
  9. (c) Q₁ at N/4, Q₃ at 3N/4 with L + [(kN/4 − cf)/f] × c.
  10. (d) Box plot: draw a scale first, then the box from Q₁ to Q₃, a line at the median, whiskers to Min and Max. Label all five values.
  11. (e) Shape: compare Mean, Median, Mode and use the box plot (longer whisker side, median position inside the box). Write 2–3 sentences.
Shape rules for (e)
ShapeOrderBox plot clue
Positively (right) skewedMean > Median > ModeRight whisker longer; median nearer Q₁
Negatively (left) skewedMean < Median < ModeLeft whisker longer; median nearer Q₃
SymmetricMean ≈ Median ≈ ModeWhiskers similar; median in middle of box

Marks-losing mistakes

  • Last class not reaching the maximum (167 needs class 151–170).
  • Using class limits instead of boundaries for L.
  • Forgetting f₀ = 0 when the modal class is the first class.
  • Using the grouped Q₁/Q₃ but forgetting the box plot needs the actual Min and Max from the raw data.
  • Box plot without a scale or without labels.
  • Saying "skewed" without saying which direction and why.
