Three golden rules of mod 26

  1. Bigger than 25? Subtract 26 (or a multiple) → 29 → 3.
  2. Negative? Add 26 → −9 + 26 = 17.
  3. The answer is always 0 – 25.

Multiples of 26 (for Hill): 26 · 52 · 78 · 104 · 130 · 156 · 182 · 208 · 234 · 260 · 286 · 312 · 338 · 364 · 390 · 416 · 442 · 468 · 494 · 520  (e.g. 114 mod 26 = 114 − 104 = 10)

1. Monoalphabetic Substitution Cipher (Slide 18)

Uses one fixed substitution alphabet for the whole message; each plaintext letter is replaced by one specific ciphertext letter and the substitution never changes.

  • One-to-one relationship · M always becomes N (MY NAME → NP OBNZ).
  • Weakness: frequency analysis — letter patterns remain (E is the most common English letter).
  • Examples: Caesar, Playfair.

General monoalphabetic key (used in practice M1–M3):

2. Caesar Cipher (Slides 20–25)

  • Also called the Shift Cipher; each letter shifted by a fixed number; monoalphabetic; one of the earliest ciphers.
  • Julius Caesar used key = 3 for military messages.
Encryption: C = E(k, p) = (p + k) mod 26    Decryption: P = D(k, c) = (c − k) mod 26 (negative → add 26)
💡 "Plus to hide, minus to find."

Key space: 1 ≤ k ≤ 25 → only 25 keys (k = 0 gives the original text) → brute-force attack tries all 25.

Table method (slide 24): HELLO, k = 4

⚠ Traps: X + 3 = 26 → 26 mod 26 = 0 = A · D − 4 = −1 → +26 = 25 = Z · Slide 21 "A = 1 implies B" means key 1, values still start at A = 0 · ignore spaces.

4. Polyalphabetic Cipher (Slide 19)

  • Uses multiple substitution alphabets; encryption changes during the message; no fixed substitution.
  • Same plain letter → different cipher letters (M → N, later M → X) · one-to-many.
  • Stronger than monoalphabetic — reduces frequency patterns. Examples: Vigenère, Vernam, Hill.

5. Vigenère Cipher (Slides 30–35)

  • Designed by Blaise de Vigenère (16th-century French) · polyalphabetic · 26 × 26 table or maths.
  • Repeat the key until it is as long as the plaintext (remove spaces first).
Method 1 (table): encryption — plaintext letter in the first row, key letter in the first column, ciphertext where they meet (G × L → R). Decryption — go to the key's row, find the cipher letter, read its column header.
Method 2 (maths) ⭐: C = (P + K) mod 26  ·  P = (C − K) mod 26 (negative → +26)

6. Vernam Cipher / One-Time Pad (Slides 36–38)

  • Letters → numbers (a = 0 … z = 25) · key length = plaintext length · random key used once → One-Time Pad, theoretically unbreakable · combines plaintext and key using XOR.
⚠ Slide 36 says XOR, but the worked example (slides 37–38) uses (P + K) mod 26. Letters given → use mod 26. Binary bits given → use XOR.

7. Hill Cipher (Slides 39–46)

  • Developed by Lester Hill (1929) · polyalphabetic · encrypts blocks simultaneously (Playfair only does pairs) · based on linear algebra / matrices.
Encryption: C = K · P mod 26    Decryption: P = K⁻¹ · C mod 26
2×2 key → split plaintext into pairs → column vectors → multiply → mod 26.
| a b | × | x | = | a·x + b·y |    | c d | × | y | = | c·x + d·y |  — "row times column"

Slide example: ATTACK, K = |2 3; 3 6|

Finding K⁻¹ — 5-step recipe

StepWhat to doSlide K = |2 3; 3 6|
1Determinant d = ad − bc (mod 26)12 − 9 = 3
2Find d⁻¹: d × d⁻¹ mod 26 = 13 × 9 = 27 → 9
3Adjoint: swap a and d, negate b and c|6 −3; −3 2|
4Remove negatives (+26)|6 23; 23 2|
5K⁻¹ = d⁻¹ × adj, mod 269 × … = |54 207; 207 18| → |2 25; 25 18|

Inverses mod 26: 1↔1 · 3↔9 · 5↔21 · 7↔15 · 11↔19 · 17↔23 · 25↔25

Decrypt FKMFIO: FK (5,10) → 260, 305 → 0, 19 = AT · MF (12,5) → 149, 390 → 19, 0 = TA · IO (8,14) → 366, 452 → 2, 10 = CK → ATTACK ✓

⚠ Extra: if the determinant is even or 13 (shares a factor with 26) there is no inverse → the key is invalid (e.g. |2 1; 4 3|, det = 2).
Checklist: K × P (key first) · top row → top result · det = ad − bc · adjoint swaps a↔d, negates b and c · remove negatives before × d⁻¹ · mod 26 at every step · pad an odd-length message.
